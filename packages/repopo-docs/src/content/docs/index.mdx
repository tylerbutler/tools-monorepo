## Features

<CardGrid>
	<Card title="Lint-like rules" icon="seti:git">
		Apply lint-like rules to any file in your git repository, and fix many violations automatically with `--fix`.
	</Card>
	<Card title="Built-in policies" icon="list-format">
		Over 50 policies for package.json, Cargo, Gleam, and general repository hygiene.
	</Card>
	<Card title="Custom policies" icon="seti:javascript">
		You can create your own policies as easily as writing a function.
	</Card>
	<Card title="Repository policies" icon="seti:folder">
		Check rules that span many files, or a file that's missing, once per run.
	</Card>
</CardGrid>
