repopo includes policies for JavaScript and package.json, Rust and Cargo, Gleam, and repository-wide checks. Import them from `repopo/policies` and add them to the `policies` array in your configuration.

## Default policies

If your configuration has no `policies` array, repopo runs `DefaultPolicies`:

- [NoJsFileExtensions](/policies/javascript/#nojsfileextensions)
- [PackageJsonRepoDirectoryProperty](/policies/javascript/#packagejsonrepodirectoryproperty)
- [PackageJsonSorted](/policies/javascript/#packagejsonsorted)

No other built-in policy runs until you configure it. Once you set `policies`, only the listed policies run. Use `policies: []` to run none.

## Enabling and configuring policies

Pass each policy to `policy(definition, config, options)`:

```ts title="repopo.config.ts"
import { policy, type RepopoConfig } from "repopo";
import {
	JsTsFileHeaders,
	NoJsFileExtensions,
	PackageJsonSorted,
	RequiredScripts,
} from "repopo/policies";

export default {
	policies: [
		// No configuration
		policy(PackageJsonSorted),

		// Configuration
		policy(RequiredScripts, { scripts: ["build", "test"] }),

		// Default configuration, with exclusions
		policy(NoJsFileExtensions, undefined, { exclude: ["^bin/"] }),

		// Configuration and exclusions
		policy(
			JsTsFileHeaders,
			{ headerText: "Copyright (c) Example Corp." },
			{ exclude: ["/generated/"] },
		),
	],
} satisfies RepopoConfig;
```

Exclusion patterns are case-insensitive regular expressions matched against repo-relative paths, not globs. See [Configuration](/usage/config/) for global exclusions and repeated policies.

To disable a built-in policy, remove it from the `policies` array.

## All built-in policies

**Scope** is *file* for policies that check each matching file and *repository* for policies that run once per check. **Fix** says whether `repopo check --fix` can correct violations; *partial* means only some violations can be fixed.

| [PackageAllowedScopes](/policies/javascript/#packageallowedscopes) | file | no | Only approved npm scopes and names |
| [PackageEsmType](/policies/javascript/#packageesmtype) | file | yes | Correct `type` field |
| [PackageFolderName](/policies/javascript/#packagefoldername) | file | no | Folder name matches package name |
| [PackageJsonProperties](/policies/javascript/#packagejsonproperties) | file | yes | Required package.json field values |
| [PackageJsonRepoDirectoryProperty](/policies/javascript/#packagejsonrepodirectoryproperty) | file | yes | Correct `repository.directory` |
