Create `repopo.config.ts` in the repository root:

```ts
import { makePolicy, type RepopoConfig } from "repopo";
import { NoJsFileExtensions, PackageJsonProperties } from "repopo/policies";

export default {
	excludeFiles: ["^vendor/"],
	policies: [
		makePolicy(NoJsFileExtensions, { exclude: ["^bin/"] }),
		makePolicy(PackageJsonProperties, {
			config: { verbatim: { license: "MIT" } },
		}),
	],
} satisfies RepopoConfig;
```

Use only `makePolicy(definition, { config, exclude, instanceId })`.
Omit options when none are needed. Set explicit unique IDs for repeated names.
`ConfiguredPolicy` represents a configured file or repository policy.

Missing or undefined `config` selects `defaultConfig`. Explicit config replaces
the whole default; there is no merge. An allowed null remains supplied.
Definitions with `requiresConfig: true` require complete config or a complete
default. A config's own `exclude` field does not configure instance exclusions.

`excludeFiles` is the repository-global option. Per-instance exclusions use
`exclude`. String patterns are case-insensitive regexes, not globs. Use
`"^vendor/"`, not `"**/vendor/**"`. RegExp values retain their flags.

Omit `policies` to enable `NoJsFileExtensions`,
`PackageJsonRepoDirectoryProperty`, and `PackageJsonSorted`.
Set `policies: []` to disable all policies. Other built-ins are opt-in.

File policies check the selected paths. Repository policies run once after
file checks against full eligible Git inventory, including with empty stdin.
Repository fixers can change files outside the selection.

See [the migration guide](/usage/migration/) for breaking changes, runner
inventory requirements, finding arrays, and resolver behavior.
